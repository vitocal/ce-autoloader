Clip & mask reveals — pure CSS lifecycle animation

No View Transitions. Each reveal is a @keyframes triggered by the element becoming [ce="defined"]. The base value is the revealed state; the animation supplies the hidden from-state.

1 · clip-path wipe

The cheapest of the five: a single inset() edge. It animates the clip shape, so the panel's rounded corners survive with round var(--r).

The one trap: the resting value must be inset(0 round var(--r)), not none. none does not interpolate with a basic shape — the browser holds the from-value and snaps at the 50% mark, turning the wipe into a pop. Measured, not guessed: at currentTime: 380 the computed value was still the from-inset, then none. 

.wipe { clip-path: inset(0 round var(--r)); }  /* revealed — never `none` */
.wipe[ce="defined"] { animation: ce-clip-wipe var(--ce-dur) cubic-bezier(.77,0,.175,1); }
@keyframes ce-clip-wipe { from { clip-path: inset(0 100% 0 0 round var(--r)); opacity: 0; } }

2 · mask sweep

A soft moving edge. --wipe is registered with @property, so it interpolates; the mask-image itself is declared once and never re-evaluated. 

@property --wipe { syntax: "<percentage>"; inherits: false; initial-value: 100%; }
.sweep[ce="defined"] {
  --wipe: 120%;
  mask-image: linear-gradient(100deg, #000 var(--wipe), transparent calc(var(--wipe) + 20%));
  animation: ce-mask-sweep var(--ce-dur) cubic-bezier(0,.55,.45,1);
}
@keyframes ce-mask-sweep { from { --wipe: -20%; } }

3 · blinds

A repeating-linear-gradient whose opaque band grows from zero. The band height is the animated variable, so one number drives the whole pattern. 

.blinds[ce="defined"] { --seg: var(--seg-max); animation: ce-blinds var(--ce-dur) var(--ce-ease); }
.blinds[ce="defined"] {
  mask-image: repeating-linear-gradient(to bottom,
    #000 0, #000 var(--seg), transparent var(--seg), transparent var(--seg-max));
}
@keyframes ce-blinds { from { --seg: 0px; } }

4 · iris

The same trick with a radial mask: the opaque radius opens from the centre outwards. 

@property --iris { syntax: "<percentage>"; inherits: false; initial-value: 0%; }
.iris[ce="defined"] {
  --iris: 150%;
  mask-image: radial-gradient(circle at 50% 50%, #000 var(--iris), transparent calc(var(--iris) + 14%));
  animation: ce-iris var(--ce-dur) var(--ce-ease);
}
@keyframes ce-iris { from { --iris: 0%; } }

5 · grid dissolve

Two perpendicular band masks combined with mask-composite: intersect. The intersection is a grid of squares that grows until the masks cover the box. 

.dissolve[ce="defined"] {
  --seg: var(--seg-max);
  mask-image:
    repeating-linear-gradient(to bottom, #000 0 var(--seg), transparent var(--seg) var(--seg-max)),
    repeating-linear-gradient(to right,  #000 0 var(--seg), transparent var(--seg) var(--seg-max));
  mask-composite: intersect;
  animation: ce-dissolve var(--ce-dur) var(--ce-ease);
}
@keyframes ce-dissolve { from { --seg: 0px; } }
