ce-autoloader

Load web components on demand
if and when they're needed.

About

ce-autoloader is a lightweight library that makes your website faster by only loading the components that are actually needed. Instead of downloading a large JavaScript file when the page opens, it waits until a user scrolls to a specific component before fetching its code.

  • Universal: Anything that exports a Custom Element works (React, Vue, Lit, Svelte, etc.).
  • Custom Strategy: Use on="visible" or on="interaction" to define when a component should be loaded.
  • Zero Friction: 5kb gzipped. No dependencies. No build steps required.
  • Shared Catalog: Define your components in a single place and use it across your app/pages.
  • Smooth Entrances: Use the lifecycle states (loading, defined) to animate components as they appear. No layout shifts.
  • Smart Scheduling: Batches custom element upgrades into single animation frames to prevent layout thrashing.
