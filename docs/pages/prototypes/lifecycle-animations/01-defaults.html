Good defaults — pure CSS lifecycle animation

No View Transitions. Every effect below is a style change on the same node, anchored on [ce] so it survives define().

1 · Skeleton + host crossfade (page-level)

One transition: opacity declared on [ce]. Because the selector matches on both sides of the upgrade, the change is animated. The shimmer is a pseudo-element, so it costs no DOM and disappears with the state. 

.host { transition: opacity var(--ce-dur) var(--ce-ease); min-height: 8.5rem; }
.host[ce="loading"] { opacity: .5; }
.host[ce="defined"] { opacity: 1; }

2 · Content entry across the shadow boundary

The page owns the host box; the component owns its guts. Both read the same attribute — the component through :host([ce="defined"]). This is the part :not(:defined) can never do, because a shadow root has no idea what :not(:defined) resolved to. 

/* inside the component's shadow root */
:host([ce="defined"]) .inner > * {
  animation: ce-rise var(--ce-dur) cubic-bezier(.16,1,.3,1) both;
}

3 · @starting-style entry

The host stays display: none until it is defined, so the display swap is a genuine first render and @starting-style supplies the from-state. Elegant, and the only technique here that needs no keyframes — but there is no skeleton while loading. 

.enter:not(:defined), .enter[ce="loading"] { display: none; }
.enter[ce="defined"] {
  display: block;
  transition: opacity .38s, translate .38s, display .38s allow-discrete;
  @starting-style { opacity: 0; translate: 0 10px; }
}

4 · Staggered list

The batch defines on one frame, so the whole list would otherwise move at once. The stagger is a transition-delay keyed on position — no JS index bookkeeping. 

.list > :nth-child(1)[ce="defined"] { transition-delay: 0ms; }
.list > :nth-child(2)[ce="defined"] { transition-delay: 70ms; }
.list > :nth-child(3)[ce="defined"] { transition-delay: 140ms; }

5 · Height expansion

A component's height is unknown until it loads, so whatever the placeholder reserves is a guess. interpolate-size: allow-keywords makes auto interpolable, which lets the guess be a floor rather than a promise: the box animates to the real height, and nothing below it moves. 

:root { interpolate-size: allow-keywords; }

.grow { height: 2.5rem; transition: height var(--ce-dur) var(--ce-ease); }
.grow[ce="defined"] { height: auto; }
